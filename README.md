# Rainy Night Theme for Omarchy

A beautiful, dark, Catppuccin-inspired theme designed specifically for modern [Omarchy](https://omarchy.org/) systems.

<img src="preview.png" alt="Rainy Night Preview" width="800">

## Installation

Install the theme directly using Omarchy's built-in theme manager:

```bash
omarchy theme install https://github.com/alihancaliskanx/omarchy-rainynight-theme.git
```

## Usage

To apply the theme globally across your system, run:

```bash
omarchy theme set omarchy-rainynight-theme
```

### Backgrounds
To cycle through the backgrounds included in this theme, use:

```bash
omarchy theme bg next
```

## Uninstallation

To remove the theme from your system, simply delete its folder:

```bash
rm -rf ~/.config/omarchy/themes/omarchy-rainynight-theme
```
